# news-freiberg-bot

[English](README.md) | **Русский**

Telegram-бот, который каждые 30 минут читает список новостей на [freiberg.de](https://www.freiberg.de/stadt-und-buerger/aktuelles/neuigkeiten), переводит заголовки и анонсы с немецкого на русский через DeepL и публикует их в Telegram-каналы и группы.

- Публикует только переведённые новости, от старых к новым, без дублей.
- Ночью (22:00–07:00 по Берлину) не обращается к сайту и ничего не публикует.
- Управляется через инлайн-меню в личке с ботом.
- Сообщает админам о проблемах: бота удалили из чата, сайт недоступен, сменилась вёрстка, закончилась квота DeepL.

## Быстрый старт

```bash
git clone https://github.com/pampot-dev/news-freiberg-bot.git && cd news-freiberg-bot
cp .env.example .env   # укажите BOT_TOKEN, DEEPL_API_KEY и ADMIN_IDS
docker compose up -d
```

Затем напишите боту в личку `/start` и добавьте его в канал или группу.
